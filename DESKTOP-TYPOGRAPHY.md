# Десктопная типографика — 18.11.2026

Только локальная доработка. Изменения не опубликованы, push и Actions не запускались.

## Размеры

- Основные описания и текст услуг: 18 px, line-height 1.65.
- Первый экран: clamp(18px, 1.25vw, 20px), вместо прежних 14–15 px.
- Название проекта: 28 px; категория: 16 px вместо 9–10; описание: 17 px вместо 12.
- Навигация, кнопки и ссылки: 16 px вместо 11–13.
- Подзаголовки пунктов услуги: 16 px, полужирные; описания: 18 px.
- Описания этапов: 18 px вместо 11–12; заголовки этапов: 22 px.
- Служебные подписи: 13–14 px.

Крупные заголовки не увеличены. Все новые правила ограничены min-width:768px. Содержание, логотип, контакты и функции не менялись; мобильные правила сохранены.

Портфолио остаётся двухколоночным. Название и категория расположены отдельными строками, увеличены интервалы до описания. Внутри раскрытой услуги пункты размещены в две колонки с ограниченной шириной. Этапы: две колонки на 768–1100 px, три на средних десктопах, пять от 1920 px. На узких десктопах навигация перенесена на отдельную строку без уменьшения текста.

## Проверки

- npm run check: 13 маршрутов успешно.
- npm run build: TypeScript, Vite и целостность Pages-артефакта успешно.
- Chromium: 1024, 1280, 1440, 1600, 1920 px; главная, проекты, услуги, о студии, контакты и кейс.
- При 100% нет горизонтальной прокрутки и пересечений элементов шапки.
- 200% проверено как эквивалентный reflow: доступная CSS-ширина уменьшена вдвое для каждой физической ширины. Проверены эффективные ширины 512, 640, 720, 800 и 960 px. Это проверка перекомпоновки, а не реальное нажатие browser zoom в интерфейсе Chrome; pinch zoom не использовался.
- 3210 замеров контраста DOM-текста: минимум 4,91:1 для обычного и 5,37:1 для крупного текста. Нарушений AA в проверенных сочетаниях нет. Текст внутри изображений не оценивается; это не полная сертификация по всем критериям WCAG.
- Проверены все шесть пунктов аккордеона и три фильтра проектов; ошибок JavaScript нет.
- На 320/375/390/430 px выборочно подтверждены прежние 17 px основного текста, 16 px кнопок и отсутствие переполнения.

Машинный отчёт: desktop-typography-checks.json. Диагностический скрипт: .qa/desktop-type.cjs. Safari и физические мониторы с разной плотностью пикселей не проверялись.
