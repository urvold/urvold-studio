# URVOLD Studio — тестовый прототип

Сайт для оценки дизайна и функциональности. Это не официальный коммерческий запуск.

React 19, TypeScript, Vite, Tailwind CSS 4, Motion и React Router. Все изображения и шрифты локальные. Без форм, аналитики, cookies, трекеров, backend и базы данных. Юридические документы и реквизиты не публикуются.

## Просмотр и проверки

Требуется Node.js 22.12+.

```bash
npm ci
npm run dev -- --host 127.0.0.1
```

Откройте `http://127.0.0.1:5173/urvold-studio/` (если Vite выберет другой порт, используйте его).

```bash
npm run check
npm run build
npm run preview -- --host 127.0.0.1
```

Production-превью: `http://127.0.0.1:4173/urvold-studio/`.

## Страницы

- `/` — главная.
- `/projects` — портфолио с фильтрацией.
- `/projects/apex`, `/projects/forma`, `/projects/elan` — демонстрационные концепты.
- `/projects/putem`, `/projects/potok`, `/projects/randomwheel` — собственные приложения.
- `/services`, `/about`, `/contacts` — услуги, студия и мессенджеры.
- Любой неизвестный адрес, включая `/missing` и `/projects/missing`, — интерфейс 404.

Все адреса расположены под `/urvold-studio/`. Итого 11 известных страниц и два проверяемых сценария 404, то есть 13 тестовых маршрутов.

## GitHub Pages

Публикация через `.github/workflows/pages.yml`: проверка, production-сборка, загрузка артефакта и deploy-pages. Запуск при push в `main` или вручную в Actions. В Settings → Pages выбран источник GitHub Actions.

Единая конфигурация пути и маршрутов — `deployment.json`. Vite использует `basePath`, BrowserRouter — соответствующий `basename`, изображения — `src/assets.ts`. `scripts/pages.mjs` создаёт отдельный `index.html` для каждой известной страницы и `404.html` для неизвестных адресов. Прямое открытие и обновление известных страниц не зависят от серверного SPA rewrite. Pages может нормализовать адреса каталогов, добавляя завершающий слеш; роутер его поддерживает.

Неизвестные адреса возвращают HTTP 404, затем React отображает фирменную страницу ошибки. Это ожидаемое поведение, а не ошибка публикации. Отдельные серверы, базы и сторонние сервисы для маршрутизации не используются.

Проверки 13 маршрутов, внутренних ссылок, файлов и префиксов ресурсов: `npm run check`. Папка `dist` генерируется при сборке и не хранится в Git.

## Конфигурация и материалы

`src/config.ts` — ссылки Telegram/MAX, проекты, услуги и пустой список будущих юридических документов. `src/App.tsx` — страницы и компоненты, `src/style.css` — адаптивный дизайн, `src/main.tsx` — точка входа.

Предоставленный владельцем логотип сохранён без замены эмблемы. Шесть обложек — реальные снимки исходных сайтов от 09.11.2026 в WebP. Manrope хранится локально, лицензия OFL — `public/licenses/Manrope-OFL.txt`.

Есть клавиатурный фокус, ссылка пропуска навигации, семантические заголовки, aria-состояния и поддержка `prefers-reduced-motion`.

Для прототипа сохранён `noindex,nofollow`. Перед коммерческим запуском нужны отдельное решение владельца, юридическая подготовка и проверка требований. Исторический отчёт первой локальной версии — `REPORT.md`; результат подготовки к Pages — `PAGES.md`.

## Текущая фирменная графика

В шапке и футере используется прозрачный `public/assets/urvold-symbol-light.png`: утверждённый силуэт с адаптированной для тёмного фона окраской. `urvold-symbol-dark.png` предназначен для светлого окружения. Источник — исходный логотип владельца без векторной аппроксимации. Голова в favicon не содержит надпись URVOLD; PNG-вариант выбирается под тему вкладок. Крупного изображения на первом экране нет. Материалы прежних локальных итераций сохранены в исходниках и не используются в текущем интерфейсе.
