# Локальная доработка URVOLD — 10.11.2026

Статус: изменения только в существующем `/workspace/urvold-studio`. Push, запуск Actions и публикация не выполнялись. Публичная версия остаётся прежней.

## Содержание

Первый экран использует заданные владельцем заголовок, подзаголовок и кнопки. Портфолио называется «Наши проекты»; карточки описывают конкретные возможности. Демонстрационные концепты и собственные приложения различаются подписями и фильтрами.

У каждой из шести услуг четыре пункта: что создаём, кому подходит, какие задачи решает, возможные функции. На страницах студии, услуг и кейсов убраны философские формулировки. Процесс состоит из пяти заданных этапов. Контакты используют заданный текст; URL Telegram и MAX не менялись.

## Фирменный знак

Использован утверждённый исходник `public/assets/urvold-original.jpg`. Его SHA-256 совпадает с приложенным владельцем изображением. Без генерации, перерисовки или изменения геометрии: только прямоугольное кадрирование и пропорциональное уменьшение.

- `urvold-head.webp`: голова без надписи, область оригинала (285,155)–(975,935). Для шапки и первого экрана.
- `urvold-lockup.webp`: полный логотип, область (140,150)–(1115,1120). Для футера.
- `favicon-32.png`, `favicon-256.png`, `favicon.ico`: та же голова без надписи, пропорционально уменьшенная на светлой подложке.

Цвета исходника сохранены. На тёмном фоне использована светлая подложка для чёрного силуэта. Удалены звёздочки; у главного знака только плавное появление без вращения и свечения. Поддерживается reduced motion.

## Просмотр


Откройте `http://127.0.0.1:5173/urvold-studio/` (либо порт из вывода Vite). Для production-превью: `npm run preview -- --host 127.0.0.1`, затем `http://127.0.0.1:4173/urvold-studio/`.
