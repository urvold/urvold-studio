# Тестовое размещение GitHub Pages

Владелец разрешил создание отдельного репозитория `urvold-studio` и тестовую публикацию. Другие репозитории не изменяются. Это не коммерческий запуск.

## Изменения

- Базовый путь `/urvold-studio/` в Vite, BrowserRouter и URL изображений.
- Единый список маршрутов в `deployment.json`.
- 11 HTML-точек входа для известных страниц и общий `404.html` для всех неизвестных адресов. Прямое открытие, обновление и завершающий слеш поддерживаются.
- GitHub Actions: npm ci → check → build → Pages artifact → deployment. Ограниченные права: чтение исходников, запись Pages и OIDC только у deploy job.
- Сохранены noindex/nofollow, маркировка прототипа, реальные Telegram/MAX и отсутствие форм/трекеров/фиктивных документов.

## Локальная проверка

`npm run check`: успешно, 13 маршрутов (11 известных + два случая 404). Проверены H1, ссылки с базовым путём, файлы изображений, отсутствие полей и форм.

`npm run build`: успешно. Созданы точки входа и 404. JS/CSS используют `/urvold-studio/assets/`, локальные шрифты включены в артефакт.

Финальный результат Actions и браузерных проверок опубликованной версии будет добавлен после размещения. Результаты Lighthouse не заявляются без измерений.
